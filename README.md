**Salt Relay** is an offline 3D crime game set in Vesper Bay. Uncover harbor corruption across eight story jobs, evade named patrol units, roadblocks and a search helicopter, or race the causeway and run deliveries by land and sea. Earn respect to unlock jobs, weapons and the Tideglass S9. Buy upgrades at Rook’s Garage, restock at the Night Market and save at the Salt Flat. Open `http://localhost:8080` in desktop Chrome. Move or drive with WASD or the arrows, sprint with Shift, brake with Space and interact or enter and exit vehicles with E. Hold the right mouse button to look or aim. Attack with the left mouse button or F, equip with 1–7 or Q and reload with R. Use V for radio, X for crew armor, M for the city map and Esc to pause or save.

## Run it

```sh
node serve.ts
```
