**Salt Relay** is an offline 3D crime game set in Vesper Bay, a coastal city where a stolen car leads to a harbor corruption scandal. Evade the patrol, finish four story jobs, race the waterfront, run courier jobs, and spend your earnings on upgrades. Open `http://localhost:8080` in desktop Chrome. Use WASD or the arrow keys to walk and drive, Shift to sprint, Space for the handbrake, E to interact or enter and exit vehicles, and hold the right mouse button to look or aim. Attack with the left mouse button or F, switch weapons with 1 or 2, and reload with R. Press M for the map and Esc to pause or save a checkpoint.

## Run it

```sh
node serve.ts
```
